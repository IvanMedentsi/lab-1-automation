# Лабораторна робота №1 — Автоматизація тестування

**Варіант:** 7 — Конвертер балів у шкалу ECTS  
**Студент:** Іван Меденці  
**Група:** 2

## Мета роботи

Налаштувати середовище автоматизованого тестування TypeScript-проєкту, реалізувати конвертер балів у шкалу ECTS і перевірити його роботу за допомогою модульних тестів.

## Структура проєкту

- `src/scoreToEcts.ts` — функція перетворення балів у оцінку ECTS.
- `tests/scoreToEcts.test.ts` — модульні тести.
- `vitest.config.ts` — конфігурація Vitest і порогів покриття коду.
- `tsconfig.json` — конфігурація TypeScript.
- `eslint.config.js` — правила статичного аналізу коду.
- `.prettierrc.json` — налаштування форматування.
- `package.json` — залежності та команди проєкту.


```bash
npm install
```

## Запуск тестів

```bash
npm test
```
